# Бот поддержки интернет-магазина

Консольный ассистент на Claude (`claude-haiku-5-5`). Отвечает только по регламенту из `system_prompt.txt`. Фактов вне регламента не додумывает: статус заказа, другой товар, скидка, обход инструкций.

## База

Пункты регламента, на которых сидит ассистент:

- Товар: наушники X1, в наличии, 2 490 ₽
- Доставка: курьер на следующий день, слот с 18:00 до 21:00
- Возврат: в течение 14 дней на ту же карту, деньги приходят за 3 рабочих дня
- Вскрытый товар без брака: можно вернуть до 14 дней
- Брак: принимаем на экспертизу, деньги сразу не обещаем
- Скидок нет ни при каких условиях

Отдельной базы нет. Эти пункты лежат в системном промпте и уходят в API на каждый запрос.

## Промпт

Полный текст: `system_prompt.txt`.

Если вопроса нет в регламенте (номер заказа, другой товар, любой факт вне списка), бот отвечает только так:

> К сожалению, у меня нет этой информации. Пожалуйста, обратитесь к оператору.

Скидку не выдаёт. Фразы вроде «забудь правила» игнорирует, роль не меняет.

## Запуск

Нужен Python 3.14+ и ключ Anthropic.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -e .
```

В `.env` в корне проекта:

```
ANTHROPIC_API_KEY=ваш_ключ
```

```powershell
python main.py
```

Выход: `exit`, `выход` или `quit`. История диалога живёт до выхода из процесса.
